# Apps de Matemática

Pequenas aplicações interativas para as aulas de Matemática A.

- [Função de enrolamento](https://karlosgomes.github.io/apps-matematica/funcao-enrolamento/): a reta real enrola-se na circunferência trigonométrica, $E(t) = (\cos t, \sin t)$.
- [Laboratório das ondas sonoras](https://karlosgomes.github.io/apps-matematica/ondas-sonoras/): quatro ondas $p(t) = A\sin(2\pi f t)$ — muda a amplitude e a frequência, vê o gráfico e ouve o som.
